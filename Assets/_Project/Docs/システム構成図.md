## システム構成図

### コア機能のみ

```text
Scripts
├─ Player
│    └─ PlayerController.cs（津久井）
│
├─ System
│    ├─ ColorManager.cs（津久井）
│    └─ AutoScroller.cs（牧平）
│
├─ Stage
│    ├─ ColorPlatform.cs（津久井）
│    └─ StageGenerator.cs（牧平）
│
├─ UI
│    └─ UIButtons.cs（大塚）
│
└─ Data
     └─ CSVLoader.cs（牧平）
```

### 津久井 優希
- PlayerController : プレイヤーのジャンプや接地判定など基本挙動を制御
- ColorManager : 赤・青状態の管理
- ColorPlatform : 床の当たり判定切替

### 大塚 葉
- UIButtons : ジャンプボタン・色切替ボタンの入力

### 牧平 愛子
- AutoScroller : 強制スクロール制御
- CSVLoader : CSVファイルの読み込み
- StageGenerator : CSVデータからステージを自動生成

---

## 拡張機能
※ 拡張機能は実装時にスクリプトを追加し，システム構成図へ反映

### 津久井 優希
- DoubleJump : 2段ジャンプ機能
- GhostRecorder : ゴーストシステム
- DashPlatform : ダッシュ床
- ColorPlatform : 紫床（安全地帯）への拡張

### 牧平 愛子
- TempoChanger : スクロール速度変化
- ReverseController : ボタン左右反転
- HoldPlatformManager : 長押し床の管理

### 大塚 葉
- JudgeSystem : Perfect / Good / Miss 判定
- ComboManager : コンボ管理
- FailureMarker : ミスした場所に×印を表示
- ResultUI : リザルト画面
