# 開発ルール

## Git
- 作業前 : Fetch（必要なら Pull）
- 作業後 : 
    Commit → Push を行う
    完成した機能等を進捗一覧で更新する．
    新しいスクリプトや機能を追加した場合はシステム構成図を更新する．


## Unity
- シーンを大きく変更するときは事前に連絡する
- 同じスクリプトを複数人で同時編集しない
- 不要なオブジェクトやファイルは勝手に削除しない
- Console にエラーがない状態で Push する
- 他人の担当ファイルを変更する場合は事前に連絡する

## スクリプトの管理担当

各スクリプトには管理担当者を置く．
他のメンバーが変更する場合は事前に連絡し，勝手に大きな仕様変更を行わないこと．
